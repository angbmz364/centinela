# Centila
An AI model trained for identify the sudamerican fruit fly (Anastrepha Fraterculus) using MobileNetV3

## Architecture

```py
/
  datasets/
    raw / # Read only datasets
    processed/ # Datasets ready for use
  models /
    # Saved trained models
  outputs /
    # Data generated while training
  src / 
    # Python code
```
